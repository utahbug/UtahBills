## Implementation

Bills now uses one native Sort disclosure on desktop and mobile. Its four ordering/filter choices are Status ▸, Tracking ID (Bill number for measures), Title and Sponsor. Title/Sponsor select ordinary ascending alphabetical order. The nested Status disclosure contains All statuses and the saved verified status values for the selected request/session scope. A restored status that is absent from the current saved scope is cleared before rendering, keeping the control and matching state consistent. Status is explicitly labelled as filtering for assistive technology. It reads and writes the same status select/state used by Advanced Search, preserving searches, saved-only state and other filters. Scope choices remain available when a search has no results, so filtering cannot trap the user. Unconfirmed source-observed statuses are not promoted to verified choices. All statuses retains those records and their original discrepancy disclosures.

Native details, buttons and the existing floating-popover helper provide bounded opaque panels, 44px targets, Tab navigation, pressed-state announcements and dismissal. Escape first closes an open Status submenu and restores its summary, then closes Sort and restores its trigger. Opening either panel does not move results. The narrow Sort panel aligns with its trigger; inherited disclosure gutters are removed and focus outlines stay inside its edges. The Sort panel is constrained to available space above/below its trigger at enlarged zoom. Existing results-per-page settings remain below the choices on phones and beside Sort on desktop. Reverse/status/latest-action ordering remains in the internal compatibility select for existing history/state and regression coverage, without redundant visible choices. Numeric bill ordering uses chamber/type prefixes and numeric comparison, with stable ties; tracking IDs retain their existing lexical order.

The Bills main container now caps its content at 1000px (1048px including desktop gutters), shared by search, toolbar and listings. This removes the old independent search cap while retaining responsive title space, status columns and stacked phone rows/bookmarks. Other pages retain their own widths. Source-link focus survives responsive reparenting.
