## Implemented scope

Search parses unquoted whitespace-separated terms as AND, commas as OR groups and double-quoted phrases as contiguous normalized text within one field. Terms may match different existing searchable fields on a record. Case/punctuation normalization preserves ordinary name order, apostrophes and bill/tracking lookup. Commas always express alternatives; quote a surname-first phrase when exact phrase behavior is desired. No synonyms or topic inference. Zero-result single-group multi-term queries offer Search for any word; broadening is explicit, labeled and reversible and retains the other filters. Search edits reset broadening. One matching set drives pagination, Copy and CSV.

Sponsor Z–A reverses existing sponsor ordering. Status A–Z/Z–A compares displayed strings, including explicit unconfirmed/unavailable qualifications; it does not rank legislative progress. Existing defaults and choices remain; deterministic secondary comparisons preserve stable results.

Bills and Activity have one Copy dropdown with all matching titles/HTTPS links, titles only and existing full-detail quoted UTF-8 CSV. The existing promised rich/plain clipboard path and complete lazy Activity loading remain. Menus use existing opaque bordered native popovers and do not reserve result space. Legislator Columns/Copy is unchanged.

Simple TRANS-006 bookmarks use browser local storage (`utahbills-bookmarks-v1`), exact request tracking IDs and session-qualified bill numbers. Outline/filled accessible listing/detail buttons toggle immediately. Saved-only controls combine with existing filters and remain visible for empty results. Activity filters exact history-route identities, never titles. Conversion aliases require the request's introduced number and the same official tracking ID on the matching 2027 catalog measure; source-observed requests cannot establish aliases. Removal clears both sides of a verified relationship. Missing records are retained and individually removable in About > Saved records on this browser. Storage failures retain visit-only state with truthful feedback. Clearing browser data can lose bookmarks; there are no accounts or GitHub/Cloudflare synchronization. Advanced monitoring, changes-since-last-visit and notifications remain deferred.
