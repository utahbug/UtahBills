- At 1280px the prior Bills search-label text sat 10px above Records; the directory search label sat 7.5px above Session/Chamber. Input tops already matched. - The owner's responsive clarification supersedes Phase 4W's mobile Records-link placement. The official link always belongs to the Search heading. Desktop displays **Official 2027 Bill Search**; narrow layouts display **Official search**, retaining the full accessible name, official URL and external icon. The archive retains its 2026 source URL/name. Breakpoint transitions preserve existing toolbar state and focus.
- Activity date/category and Calendar month/type use one shared selected-caption helper, native selects and a small Lucide chevron. The current caption determines intrinsic width, automatically responds to fonts/container size, wraps at enlarged text sizes, and reserves a 14px text-to-arrow gap (30px trailing space minus 12px artwork and 4px edge inset). Long options can move to the next control row and their captions wrap instead of clipping. The original native select overlays the caption for touch/keyboard interaction; the duplicate caption is aria-hidden and the wrapper exposes visible keyboard focus. No selection/date/filter logic changed.
- Calendar has one 8px-spaced divider before Events, after the grid when expanded. Ordinary category letters follow their regular-weight descriptions; descriptions align with the time. Deadline icon, exact classifications, legend, revised/cancellation semantics, grouped dates and Copy remain intact.
- Activity empty states describe the selected period and keep useful browsing links. Zero totals are hidden only for empty results. Coverage and baseline qualifications remain in Info; undated controls remain available. Only the final visible Activity row loses its bottom border; internal record and shared footer boundaries remain.
- Bills pagination previously had 12px bottom margin plus 36px main padding (48px to the footer). Scoped spacing now gives 10px above and below its existing 44px controls. The shared minimum page height remains, including short/empty pages. Activity pagination uses the same compact margin without changing paging behavior.
- Shared Contact artwork is Lucide message-circle, 16px with 1.5 stroke and muted blue-gray. The existing 44px target, accessible name, tooltip, route, sticky position, footer and temporary email configuration remain unchanged.
