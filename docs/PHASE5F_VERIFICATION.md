# Phase 5F — Bills search, responsive controls and Contact icon

October 26, 2026 (Mountain). Baseline: clean synchronized Main `183b35d76bae979aee6bfb6d1ea90ba51a0d1b27`, successful [Phase 5E build/deployment 40258126930](https://github.com/utahbug/UtahBills/actions/runs/40258126930). No source acquisition is part of this interface batch.

## Implementation and preserved behavior

- **One search grid and one official link.** At widths through 700px, current-session Records and Search stack and the existing link moves to the Records heading. Above 700px, both fields share grid heading/input rows, including when heading text wraps. The link's right edge follows the Search input border, excluding the 44px Info target plus its 8px gap. Narrow wording is “Official search”; its full accessible name and official year-specific URL remain. The archive has no Records selector and retains its link in the Search heading. Obsolete flex/heading-margin overrides were removed.
- **One Search Info.** The former count-popover content now lives inside the existing legislative-data disclosure (`#count-info` remains an evidence-content identifier, not a second control). Saved/source totals, verified versus unconfirmed statuses, distinct verified/observation dates, excluded converted/confidential/unpublished requests, empty-index qualifications, historical limitations, stale-snapshot warnings and source/refresh links remain. Escape closes the disclosure and restores its trigger. No permanent explanation was added.
- **Mobile Sort / More / Copy.** Sort contains the same native ordering and page-size selects; More contains only Export CSV; Copy remains far right. Desktop retains visible Sort and Per page, with count and actions to the right. The same DOM controls, event handlers, preferences and history are reused. Empty results hide unavailable actions while Search Info stays available. Both menus support keyboard/touch, Escape, outside dismissal and focus restoration. Panels remain inside the visual viewport. Sort prefers space below the toolbar, leaving Advanced search reachable; CSV prefers space above to avoid partially covering the first result link. Both adapt when viewport space is constrained.
- **Breakpoint focus.** Testing reproduced loss of native-select focus when CSS hid its old container before the media-change handler moved it. Controls now move before that container is hidden. Link and select focus survive both sides of 700/701px. The generic empty-controls grid no longer overrides the explicit Bills toolbar grid. The existing 132px minimum supports three 44px targets at extreme CSS zoom.
- **Archive Advanced search.** Removed the override that placed content in the disclosure-arrow gutter. All five filters share the normal 1.25rem content inset with heading text, consistent label/select edges and compact wrapping. An 8px gap separates the disclosure from Search. Archive styling, footer/deep links and filter functions remain unchanged.
- **Contact.** Existing Lucide mail artwork sits inside a thin, unfilled circular outline. The existing 44px header link, muted color, `Contact UtahBug` accessible name/tooltip, sticky placement and internal `#contact` destination remain. Temporary email configuration and Contact content are unchanged.
